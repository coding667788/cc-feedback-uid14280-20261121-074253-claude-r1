实现受管工位连接事件模拟器。虚构介质有保管类别与固定 ID，工位同时可容纳多件介质，但输入中的互斥类别及工位组合禁止在同一逻辑时刻同时可读。实际连接和可信授权分别到达，并带设备事件时间、通道序号、连接代次；每通道可重传和有限乱序。显式 watermark 表示该时刻及之前不会再产生合法新事件，不能把超过水位到达的迟报默默并入已发布历史。同一时刻处理完所有工位的批量变化后再输出，先断开、再连接、再应用授权；授权绑定工位、设备、连接代次及截止时间，左闭右开。连接与授权跨通道，未到齐期间不标为可读。
ingest 事务内归并同 ID 重试，冲突整批拒绝；推进 watermark 同时持久化可读集合、违规段与相应证据 ID。report 返回已封存区间的最早违规以及全部最大同证据段，不枚举时间刻度。规则包括再插入旧代授权无效、同刻跨工位迁移只有旧工位断开才可在新工位连，输入重复连接按冲突拒绝而不推进水位。测试覆盖授权先到、过期恰逢解绑、同一时刻有多种中间状态但最终无违规、迟到触发全批原子回滚、重启后回放和两个进程竞争同一水位。

使用 Windows 原生 Python 3.12、标准库和 CPU，从空仓库实现，所有夹具用本地虚构数据。命令格式为 python -m solution <命令> CASE.json，涉及持久状态的命令带 --db DB.sqlite。标准输出为 UTF-8 JSON，同一逻辑输入产生同一结果；结构错误给出可定位的错误码及字段位置。交付可直接运行的样例、README（含完整输入输出定义与复现命令）和可用 python -m unittest discover -s tests -v 执行的断言测试。
